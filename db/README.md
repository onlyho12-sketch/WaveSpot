# db · SQLite

- `wavespot.db` : 실행 중 생성되는 DB 파일 (저장소에 올리지 않음). 지우면 다음 실행 때 새로 만들어짐
- `schema/schema.sql` : 테이블 정의 (backend/app/models.py 에서 자동 생성)

| 테이블 | 내용 |
|---|---|
| examsession | 시험(교시) · 좌석 배치 · 진행 상태 (setup → baseline → running → ended) |
| alloweddevice | 허용 목록 · 입실 전 기준선 · 수색 후 미발견으로 옮긴 신호 |
| searchrequest | 정밀 수색 요청 · 구역 1 · 2순위 · 위험 점수 · 근거 카드(JSON) · 수색 부위 · 결과 |
| agentevent | 에이전트 판단 기록 (단계: 준비 · 신호 감지 · 위치 추정 · 수색 · 결과 반영 · 장비) → 시험 후 리포트 · 이의 제기 근거 |
| supervisornote | 감독관 의견 · 메모 |
| faultrecord | 장애 · 복구 기록 (수신기 끊김 · 서버 재시작 · 모델 오류 · 망 장애 등, 복구 시간 · 놓친 측정값) |
| chainentry | 추가만 되는 기록 + 해시 체인 (판단 기록 · 수색 결과 · 의견). 한 줄이라도 고치면 그 뒤 해시가 어긋남 |
| accesslog | 열람 · 변경 · 내보내기 기록 (역할 · 허용/거부) |
| attackrun | 우회 · 해킹 재현과 탐지 기록 (재현 시각 · 탐지 시각 · 탐지된 기기 → 사다리 단계) |

- `checkpoint.json` : 10초마다 저장하는 판단 상태 (허용 목록 · 조사 중 기기 · 사다리 단계)

개인정보: 기기 주소는 수신기에서 해시한 값만 저장, 수험생 이름 대신 좌석 번호만 기록, Wi-Fi 는 길이 · 간격만 (내용 미수집).
원시 신호(판단 기록의 측정값 · 순회 세기)는 7일(이의 제기 기간) 지난 교시부터 서버를 켤 때 자동으로 지움. 판단 기록 · 결과 · 해시 체인은 남김.
